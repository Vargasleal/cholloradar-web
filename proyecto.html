El proyecto CholloRadar

CholloRadar es un prototipo independiente para explorar ofertas de tecnología, aspiradoras y robots de cocina. Esta web presenta la experiencia propuesta para evaluar una futura integración de datos autorizados.

Estado actual: demostración funcional.
Los seis productos y sus precios son ficticios. No hay ofertas verificadas, tiendas vinculadas, compras, históricos ni alertas activas. No se ha acreditado acceso concedido a la API de Comparaloo.

Qué puedes probar hoy

Buscar productos, combinar búsqueda y categoría, ordenar precios ficticios y abrir el detalle de cada ejemplo. También puedes limitar el presupuesto y consultar los detalles de cada producto de demostración.

Integración planificada con Comparaloo

Plan propuesto, no una integración activa ni una colaboración confirmada. Antes de usar datos reales será necesario obtener autorización y revisar la documentación, la cobertura, los límites de uso y las condiciones del proveedor. No se presuponen endpoints ni capacidades de su API.

  1. Acceso y validación. Solicitar acceso y confirmar qué datos pueden mostrarse, almacenarse y actualizarse, incluida la atribución exigida.
  2. Conexión segura. Implementar un servicio de servidor o proceso autorizado que consulte la API. Las credenciales quedarían en secretos del entorno de ejecución, nunca en el navegador ni en este repositorio.
  3. Datos con contexto. Normalizar identificador, producto, comercio, precio, moneda, enlace y fecha de consulta según los campos realmente disponibles. Señalar disponibilidad desconocida y datos caducados.
  4. Publicación verificada. Sustituir la demo únicamente tras validar respuestas, permisos y enlaces. Retirar ofertas caducadas y mostrar avisos si falla la actualización.

Históricos y alertas: todavía no disponibles

No presentamos descuentos porcentuales, precios tachados ni “mínimos históricos” sin evidencia. Un histórico futuro requerirá observaciones reales fechadas y permiso para conservarlas. Las alertas de Telegram son una posible fase posterior: aquí no se solicita ni utiliza ningún token, chat ID o dato de suscriptores.

Privacidad y transparencia comercial

Esta versión no incluye cuentas, formularios, analítica, cookies propias ni almacenamiento local. Las búsquedas se procesan en tu navegador y no se envían a una API. GitHub Pages puede tratar datos técnicos de conexión como proveedor del alojamiento, conforme a su declaración de privacidad.

No hay enlaces de afiliación en esta demo. Si se incorporan en el futuro, se identificarán junto a los enlaces y se explicará su funcionamiento antes de activarlos.

Una base sencilla y revisable

Una experiencia ligera, sin dependencias externas. El código y el catálogo de ejemplo pueden consultarse en Vargasleal/cholloradar-web. El objetivo de esta fase es demostrar la interfaz y el plan de integración; no vender productos.
